Первая установка
    python -m venv venv
    .\venv\Scripts\Activate
    pip install -r requirements.txt

Запуск
    .\venv\Scripts\Activate
    python app.py
    Откройте http://localhost:5000 — при первом запуске создайте администратора.

Доступ из сети (по умолчанию приложение доступно только с этого компьютера)
    $env:SWITCHMAP_HOST = "0.0.0.0"
    $env:SWITCHMAP_PORT = "5000"        (необязательно)
    python app.py
    За HTTPS-прокси дополнительно: $env:SWITCHMAP_HTTPS = "1"

Уведомления в Telegram и на почту
    Настраиваются на странице «Уведомления» (значок самолётика слева, только для администратора).
    Серверу SwitchMap нужен доступ к api.telegram.org (или HTTP-прокси, он указывается там же)
    и/или к почтовому серверу. Чтобы приходили события, включите периодический опрос в «Настройках».
    Свой сервер Bot API (необязательно): $env:SWITCHMAP_TELEGRAM_API = "http://bot-api.local:8081"

Поиск коммутаторов в сети и импорт из NetBox
    Страница «Поиск и импорт» (значок радара слева, только для администратора) или кнопка
    «Найти в сети» на главной. Серверу нужен доступ к коммутаторам по UDP 161 (SNMP).
    NetBox: нужен адрес NetBox и API-токен (достаточно прав только на чтение).

Забыли пароль администратора (из консоли на сервере)
    python app.py reset-password admin

Важные файлы рядом с app.py
    switches.db        — база
    switchmap.secret   — ключи: подпись сессий и шифрование паролей SNMPv3.
                         Храните отдельно и переносите вместе с базой: без него
                         пароли SNMPv3 придётся ввести заново. В резервные копии не входит.
    backups\           — резервные копии базы
