SwitchMap 以清晰的示意图展示网络中的交换机：哪些端口在使用、每根线缆通往哪里、哪台设备接在哪里、端口是否过载。数据通过 SNMP 直接来自交换机——无需在交换机上安装任何软件，只需启用 SNMP。

# 需要准备什么 {#requirements}

- 一台运行 SwitchMap 的电脑或服务器，能通过网络访问交换机（UDP 161 端口）。
- 交换机上已启用只读 SNMP。不同型号的设置方法见[在交换机上启用 SNMP](/help/snmp-vendors)。
- 交换机的管理 IP 地址。如果数量很多或记不全，SwitchMap 可以自动找到它们。

# 第 1 步：添加交换机 {#add}

有两种方式：

1. **逐台添加。** 在首页点击 **添加交换机**，输入 IP 地址和 SNMP 设置，然后点击 **检查并填写**——名称、端口数和型号会自动填入。
2. **一次全部添加。** 点击 **网络发现**，输入网络（例如 `192.168.1.0/24`）——SwitchMap 会检查每个地址并列出找到的交换机。勾选需要的设备，点击 **添加所选**。

如果您使用 NetBox，也可以从中导入交换机——见[从 NetBox 导入](/help/netbox)。

# 第 2 步：轮询交换机 {#poll}

打开一台交换机，点击 **通过 SNMP 轮询**。几秒后示意图上会显示端口状态：亮色表示有链路，暗淡表示无链路。**端口** 表格显示每个端口的速率、利用率、错误和 VLAN。

要让数据自动更新，请打开 **设置**（左下角的齿轮图标）并开启 **定期轮询**。5 分钟的间隔几乎适合所有人。

# 第 3 步：绘制连接 {#connections}

示意图还能显示交换机本身不知道的信息：哪个端口经过配线架通往哪里。点击 **编辑**，添加配线架，然后先点击交换机端口，再点击配线架端口，并为连接加上标注（例如“财务部，214 室”）。详见[端口示意图与连接](/help/port-map)。
