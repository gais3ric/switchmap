如果您的交换机已登记在 NetBox 中，可以将它们连同名称、IP 地址和端口数一起导入 SwitchMap。栏目：**发现与导入 → NetBox**（仅管理员）。

# 连接 {#token}

1. **NetBox 地址**——例如 `https://netbox.company.local`。
2. **API 令牌**——在 NetBox 中创建：用户资料（右上角）→ **API Tokens** → **Add a token**。**只读** 令牌即可。两种令牌格式均可使用（经典格式和新的 `nbt_…`）。
3. 如果 NetBox 使用自签名证书，请取消勾选 **验证服务器证书**。
4. 点击 **检查并保存**。

令牌在 SwitchMap 服务器上加密存储，不会发送到浏览器。

# 导入 {#import}

1. 选择筛选条件：**站点**、**角色**（例如“Access switch”）、**标签**。**仅状态为“Active”** 会隐藏已退役和计划中的设备。
2. 点击 **显示设备**。
3. 勾选需要的设备（默认勾选带 IP 的新设备），点击 **导入所选**。

IP 地址取自设备的 **Primary IP**，端口数取自其物理接口。在同一页面填写 SNMP 设置——它们将应用于所有导入的交换机。

# 匹配 {#matching}

满足以下任一条件时，NetBox 设备被视为已添加：

1. 已关联（该交换机之前从 NetBox 导入过）；
2. 或 IP 地址相同；
3. 或名称相同。

对于这类设备可以看到将发生的变化。**对于已添加的设备，从 NetBox 更新名称和 IP** 用于开启更新。端口图、连接和历史不会改变。

# 同步 {#sync}

**已关联的交换机** 区块：**立即同步** 从 NetBox 更新所有已关联交换机的名称和 IP。**每小时自动执行** 会按计划同步。新设备不会自动添加——只能通过导入。

已关联交换机的页面上有指向其 NetBox 记录的 **NetBox** 链接。
