# 侧边菜单 {#menu}

| 图标 | 栏目 | 内容 |
|---|---|---|
| 服务器 | 交换机 | 交换机列表及其可用性、利用率和告警。在这里添加新交换机。 |
| 示意图 | 拓扑 | 基于 LLDP 的交换机互联图。 |
| 时钟 | 变更日志 | 谁在何时改了什么；撤销更改。 |
| 数据库 | 数据与备份 | 历史保留期限、备份、恢复。 |
| 雷达 | 发现与导入 | 网络发现和 NetBox 导入（仅管理员）。 |
| 纸飞机 | 通知 | Telegram 和邮件消息（仅管理员）。 |
| 放大镜 | 查找设备 | 按 MAC、IP、名称和端口描述搜索。 |

菜单底部依次为：**帮助**、浅色/深色主题切换、**设置**（轮询和告警阈值）以及您的个人资料。

# 个人资料与语言 {#language}

点击菜单底部带有您姓名缩写的圆圈。您可以在这里修改密码、打开帮助并选择 **界面语言**。“跟随系统”会使用浏览器语言，通常与电脑操作系统的语言一致。

变更日志、事件以及 Telegram/邮件消息使用统一的语言——由管理员在 **设置 → 语言** 中选择。

# 事件 {#events}

顶部栏的铃铛显示最近的事件：端口断开或恢复、利用率过高、端口错误、交换机不可达。铃铛上的数字表示未读数量。点击事件会打开对应交换机并高亮该端口。

# 快捷键 {#keys}

| 按键 | 操作 |
|---|---|
| [[Ctrl]] + [[K]] 或 [[/]] | 查找设备 |
| [[Esc]] | 关闭窗口或菜单 |
| [[↑]] [[↓]] [[Enter]] | 选择搜索结果 |

# 角色 {#roles}

**管理员** 可以执行所有操作。**观察者** 可以查看所有页面并轮询交换机，但不能修改任何内容——编辑按钮对其隐藏。详见[用户与角色](/help/users)。
