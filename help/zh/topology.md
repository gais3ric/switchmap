**拓扑** 页面会绘制哪台交换机通过哪些端口与哪台相连。数据来自 **LLDP**——相邻设备互相通报自身信息的协议。

# 需要什么 {#requirements}

1. 在交换机上启用 LLDP——各厂商的命令见[启用 SNMP](/help/snmp-vendors)。很多型号默认已启用。
2. 交换机必须已添加到 SwitchMap，并设有 IP 地址和 SNMP 访问。

# 阅读拓扑图 {#read}

图例位于地图一角：

| 标记 | 含义 |
|---|---|
| 蓝色条 | SwitchMap 中的交换机；圆点表示是否可达 |
| 浅蓝色条 | 服务器或已分配到端口的设备 |
| 橙色条 | 未知的 LLDP 邻居——不在 SwitchMap 中的设备（无线接入点、IP 电话、其他交换机） |
| 实线 | 来自 LLDP 的物理链路 |
| 虚线 | 手动分配到端口的设备 |

将鼠标悬停在连线上可查看两端的端口。

可用鼠标拖动地图、用滚轮缩放，**适应窗口** 按钮可让整张图重新显示在屏幕上。点击交换机会打开带有 **打开交换机** 按钮的卡片。

> **提示：** 在[网络发现](/help/add-switch#discovery)中开启 **跟随 LLDP 邻居** 后，SwitchMap 会自动找到在此图上作为邻居出现的交换机。

# 没有链路时 {#empty}

- 交换机或个别端口上禁用了 LLDP。
- 交换机不通过 SNMP 提供 LLDP-MIB（简单型号常见）。
- 部分 Cisco 设备默认只使用 CDP——请用 `lldp run` 启用 LLDP。
