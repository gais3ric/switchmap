| 术语 | 含义 |
|---|---|
| **交换机** | 电脑、电话、无线接入点和其他交换机通过网线连接的设备，负责在它们之间转发数据 |
| **端口** | 交换机上用于连接一根网线的接口 |
| **链路** | 端口已连接，且另一端有通电的设备 |
| **配线架** | 机柜中的一排接口，来自各办公室的线缆汇集于此，再用短跳线连接到交换机 |
| **RJ-45** | 常见的铜缆网络接头（双绞线） |
| **SFP** | 可更换模块的插槽——通常用于光纤，支持更远距离和更高速率 |
| **MAC 地址** | 网络设备唯一的“出厂编号”，例如 `00:1A:2B:3C:4D:5E`。交换机会记住哪个 MAC 位于哪个端口之后 |
| **IP 地址** | 设备在网络中的地址，例如 `192.168.1.25` |
| **VLAN** | 交换机内部的逻辑“子网”：不同 VLAN 的端口彼此不能直接通信。例如 VLAN 10 用于财务，VLAN 20 用于电话 |
| **中继（Trunk）** | 同时承载多个 VLAN 的端口——通常是连接另一台交换机的链路 |
| **上联（Uplink）** | 通往“上层”的端口——连接另一台交换机或网络核心 |
| **SNMP** | SwitchMap 用来查询交换机状态的协议。见[什么是 SNMP](/help/snmp-basics) |
| **Community** | SNMP v2c 的“密码” |
| **LLDP** | 相邻设备互相通报自身信息的协议。[拓扑](/help/topology)基于它构建 |
| **端口描述（ifAlias）** | 在交换机配置中为端口设置的标签（例如“uplink-core”） |
| **端口利用率** | 流量占端口速率的百分比 |
| **端口错误** | 传输中损坏的数据，通常说明线缆或接头有问题 |
| **速率与双工** | 端口速率（100 Mbit/s、1 Gbit/s、10 Gbit/s）以及“双向同时传输”模式。线缆两端必须一致 |
| **PoE** | 通过网线为设备（电话、摄像头、无线接入点）供电 |
| **Ping** | 简单检查：设备是否在网络上有响应 |
| **NetBox** | 网络设备资产管理系统。SwitchMap 可以从中[导入](/help/netbox)交换机 |
