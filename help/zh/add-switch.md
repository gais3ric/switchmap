# 手动添加 {#manual}

1. 在首页点击 **添加交换机**。
2. 输入管理 **IP 地址** 和 SNMP 设置（版本、community 或 v3 用户）。
3. 点击 **检查并填写**。如果交换机有响应，SwitchMap 会填入其名称、端口数和型号；否则会显示原因（例如“SNMPv3 密码错误”）。
4. 如有需要添加配线架，然后点击 **创建交换机**。

也可以不填 IP 地址添加交换机——仅作为线缆记录用的示意图。但这样就没有端口状态、利用率和设备搜索。

# 网络发现 {#discovery}

**发现与导入** 栏目（雷达图标）可一次检查大量地址。

1. 在 **网络和地址** 中填写扫描范围，用逗号或换行分隔：
   - 网络：`192.168.1.0/24`；
   - 范围：`10.0.0.1-10.0.0.50`，或简写为 `10.0.0.1-50`；
   - 单个地址：`10.0.5.7`。
2. 填写 SNMP 设置。v2c 可以列出多个 community（用逗号分隔），会逐一尝试。
3. **跟随 LLDP 邻居**：已发现的交换机会报告其邻居地址，这些地址也会被检查。这样可以找到您未列出的网络中的交换机。
4. 点击 **开始扫描**。扫描在服务器上进行——可以关闭页面，稍后再回来。
5. 在结果表格中勾选需要的设备，按需修改名称，然后点击 **添加所选**。

每次扫描最多检查 4096 个地址（一个 /20 网络）。已添加的交换机会标记为“已添加”，不会重复。

> **提示：** **交换机 / 所有设备** 筛选——默认只显示看起来像交换机的设备。同样响应 SNMP 的打印机、UPS 和服务器会被隐藏。

# 从 NetBox 导入 {#netbox}

如果您的交换机已登记在 NetBox 中，可连同名称、IP 地址和端口数一起导入。见[从 NetBox 导入](/help/netbox)。

# 找不到交换机 {#not-found}

- 检查 SwitchMap 服务器能否访问交换机的 **UDP 161** 端口（防火墙、交换机上的 ACL）。
- 确认交换机已启用 SNMP，并允许来自 SwitchMap 服务器地址的访问——很多型号只接受白名单中地址的请求。
- 检查 community 或 v3 凭据——它们区分大小写。

详见[故障排除](/help/troubleshooting)。
