# 阅读示意图 {#read}

交换机页面显示 **机柜视图**：交换机本身及其配线架，端口排列与前面板一致。

| 看到的 | 含义 |
|---|---|
| 亮色端口 | 有链路——已连接设备且设备通电 |
| 暗淡端口 | 无链路（根据最近一次轮询） |
| 端口底部的彩色条 | 端口利用率：30% 以下、60% 以下、阈值以下和超过阈值——颜色见示意图上方的图例 |
| 红色边框 | 利用率超过告警阈值 |
| 编号旁的字母 **T** | 端口已标记为中继（连接另一台交换机的上联） |
| 底部带“凸舌”的端口 | SFP（光纤）；普通端口为 RJ-45（铜缆） |
| 端口上的彩色标记 | 端口所属 VLAN（可以为 VLAN 指定颜色） |

将鼠标悬停在端口上可查看提示：接口名称、描述、速率、利用率、错误和已连接的设备。**端口利用率** 开关用于显示或隐藏彩色条。

# 通过配线架的连接 {#connections}

交换机不知道线缆经过配线架后通往哪里，但您知道——只需绘制一次：

1. 点击 **编辑**。
2. 如果还没有配线架——**设置 → 配线架 → 添加配线架**：名称、端口数、位置（交换机上方或下方）。
3. 先点击交换机端口，再点击配线架端口。
4. 填写线路通往哪里（例如“214 室，打印机”）以及线缆颜色。
5. 点击 **保存**。

如果线缆不经过配线架直接连到设备，请右键单击端口 → **直接分配…**

所有连接都列在 **设置 → 交换机 → 端口连接** 中，可在那里修改或删除。

# 端口类型与中继 {#trunk}

右键单击交换机端口：

- **RJ-45（铜缆）** 或 **SFP（光纤）**——仅影响在示意图上的外观；
- **标记为中继**——用于连接另一台交换机的端口。中继端口在[通知](/help/notifications)中被视为重要端口，设备搜索也会知道此类端口后面是整个网络而不是一台设备。

# VLAN {#vlan}

SNMP 轮询后，**设置 → VLAN** 会列出交换机的 VLAN。点击 VLAN 旁的色块并选择颜色——示意图上该 VLAN 端口的标记会变为该颜色。VLAN 筛选会淡化其他所有端口。每个端口的 VLAN 也显示在 **端口** 表格中。

# 端口上的设备 {#devices}

点击 **通过 SNMP 轮询** 后，右侧会打开 **端口与设备（SNMP）** 面板：显示所有接口以及交换机在每个端口上看到的 MAC 地址，能解析时还会显示 IP 和名称。点击面板中的端口可展开设备列表。**分配到端口** 可将设备连同您的备注固定到端口——即使设备关机，[搜索](/help/search)也能找到它。

# 导出 {#export}

**导出** 菜单：

- **Excel**——端口、连接、配线架和设备分别在不同工作表；
- **PDF 文档**——可打印或交给施工方的连接图；
- **CSV**——用于自制报表的单独表格；
- **变更历史**——此交换机在[日志](/help/backups#audit)中的所有修改。
