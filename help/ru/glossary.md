| Термин | Что это |
|---|---|
| **Коммутатор (свитч)** | Устройство, к которому кабелями подключаются компьютеры, телефоны, точки доступа и другие коммутаторы. Передаёт данные между ними |
| **Порт** | Гнездо на коммутаторе для одного кабеля |
| **Линк** | Порт подключён, и с другой стороны есть включённое устройство |
| **Патч-панель** | Панель с гнёздами в стойке, куда приходят кабели из кабинетов. С коммутатором она соединяется короткими кабелями — патч-кордами |
| **RJ-45** | Обычный медный сетевой разъём («витая пара») |
| **SFP** | Гнездо для сменного модуля — обычно оптического, для больших расстояний и скоростей |
| **MAC-адрес** | Уникальный «заводской номер» сетевого устройства, например `00:1A:2B:3C:4D:5E`. Коммутатор запоминает, за каким портом какой MAC |
| **IP-адрес** | Адрес устройства в сети, например `192.168.1.25` |
| **VLAN** | Логическая «подсеть» внутри коммутатора: порты разных VLAN не видят друг друга напрямую. Например, VLAN 10 — бухгалтерия, VLAN 20 — телефоны |
| **Транк** | Порт, по которому идут сразу несколько VLAN — обычно соединение с другим коммутатором |
| **Uplink** | Порт, ведущий «наверх» — к другому коммутатору или к ядру сети |
| **SNMP** | Протокол, по которому SwitchMap узнаёт у коммутатора его состояние. См. [Что такое SNMP](/help/snmp-basics) |
| **Community** | «Пароль» для SNMP v2c |
| **LLDP** | Протокол, по которому соседние устройства рассказывают друг другу о себе. Из него строится [топология](/help/topology) |
| **Описание порта (ifAlias)** | Подпись порта, заданная в настройках коммутатора (например, «uplink-core») |
| **Загрузка порта** | Сколько процентов от скорости порта занято трафиком |
| **Ошибки порта** | Повреждённые при передаче данные. Обычно признак плохого кабеля или разъёма |
| **Скорость и дуплекс** | Скорость порта (100 Мбит/с, 1 Гбит/с, 10 Гбит/с) и режим «одновременно в обе стороны». Должны совпадать с обеих сторон кабеля |
| **PoE** | Питание устройств (телефонов, камер, точек доступа) прямо по сетевому кабелю |
| **Ping** | Простая проверка: отвечает ли устройство по сети |
| **NetBox** | Система учёта сетевого оборудования. SwitchMap умеет [импортировать](/help/netbox) из неё коммутаторы |
