# Роли {#roles}

| Роль | Может |
|---|---|
| **Администратор** | Всё: добавлять и менять коммутаторы, настройки, уведомления, пользователей, восстанавливать копии |
| **Наблюдатель** | Смотреть все страницы, опрашивать коммутаторы, искать устройства, проверять доступность. Ничего не меняет |

Наблюдатель подходит для дежурных, техподдержки и подрядчиков. Кнопки изменения у него скрыты, а сервер дополнительно проверяет права при каждом действии.

# Добавление пользователя {#add}

Раздел **Пользователи** (меню профиля → **Пользователи**, только администратор) → **Добавить пользователя**: имя, роль, пароль не короче 8 символов. Сообщите пароль пользователю — сменить его он сможет сам в меню профиля.

# Блокировка и пароли {#manage}

- **Заблокировать** — пользователь сразу теряет доступ, но остаётся в списке (его действия в журнале сохраняются).
- **Задать пароль** — новый пароль; все сессии пользователя на других компьютерах завершатся.
- Последнего администратора нельзя удалить, заблокировать или понизить — так в систему всегда можно войти.

После 5 неудачных попыток входа подряд вход для этого имени с этого адреса временно блокируется. Неудачные попытки записываются в журнал изменений.

# Забыли пароль администратора {#reset}

Задайте новый пароль из командной строки на сервере, где установлен SwitchMap:

| Система | Команда |
|---|---|
| Windows (от имени администратора) | `& "C:\Program Files\SwitchMap\switchmap.exe" reset-password admin` |
| Linux | `sudo switchmap reset-password admin` |
| Из исходников | `python app.py reset-password admin` |

Если пользователя с таким именем нет, команда предложит создать администратора.

# Сессии {#sessions}

Без галочки **Запомнить меня** сессия завершается после 12 часов бездействия, с галочкой — через 30 дней.
