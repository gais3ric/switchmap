Если ваши коммутаторы учтены в NetBox, их можно перенести в SwitchMap вместе с названиями, IP-адресами и числом портов. Раздел **Поиск и импорт → NetBox** (только администратор).

# Подключение {#token}

1. **Адрес NetBox** — например, `https://netbox.company.local`.
2. **API-токен** — создайте в NetBox: профиль пользователя (справа вверху) → **API Tokens** → **Add a token**. Достаточно токена **только для чтения**. Подходят токены обоих форматов (старые и новые `nbt_…`).
3. Если у NetBox самоподписанный сертификат, снимите галочку **Проверять сертификат сервера**.
4. Нажмите **Проверить и сохранить**.

Токен хранится на сервере SwitchMap в зашифрованном виде и в браузер не передаётся.

# Импорт {#import}

1. Выберите фильтры: **сайт**, **роль** (например, «Access switch»), **тег**. Галочка **Только в статусе «Active»** скрывает списанные и планируемые устройства.
2. Нажмите **Показать устройства**.
3. Отметьте нужные (по умолчанию отмечены новые устройства с IP-адресом) и нажмите **Импортировать выбранные**.

IP-адрес берётся из **Primary IP** устройства, число портов — из его физических интерфейсов. Параметры SNMP укажите на этой же странице — они будут применены ко всем импортированным коммутаторам.

# Сопоставление {#matching}

Устройство NetBox считается уже добавленным, если совпадает:

1. связь (коммутатор уже был импортирован из NetBox);
2. или IP-адрес;
3. или название.

Для таких устройств видно, что изменится. Галочка **У уже добавленных — обновить название и IP из NetBox** включает обновление. Схема портов, подключения и история при этом не меняются.

# Синхронизация {#sync}

Блок **Связанные коммутаторы**: кнопка **Синхронизировать сейчас** обновляет названия и IP всех связанных коммутаторов из NetBox. Галочка **Автоматически раз в час** делает это по расписанию. Новые устройства автоматически не добавляются — только через импорт.

На странице связанного коммутатора есть ссылка **NetBox** на его карточку.
