**SNMP** (Simple Network Management Protocol) — стандартный способ узнать у сетевого устройства его состояние: список портов, включены ли они, сколько трафика прошло, какие MAC-адреса видны, температуру и загрузку процессора. Его поддерживают практически все управляемые коммутаторы.

SwitchMap только **читает** данные — он ничего не меняет на коммутаторах. Поэтому достаточно доступа «только чтение».

Запросы идут на порт **UDP 161** коммутатора.

# v2c или v3 {#v2c-or-v3}

| | SNMP v2c | SNMP v3 |
|---|---|---|
| Как проверяется доступ | По «слову-паролю» — **community** | Пользователь и пароль |
| Шифрование данных | Нет — всё идёт открытым текстом | Есть (AES, DES) |
| Настройка | Одна строка на коммутаторе | Несколько строк |
| Когда выбирать | Изолированная сеть управления | Во всех остальных случаях |

> **Важно:** community `public` знают все. Если используете v2c, задайте своё сложное слово и ограничьте доступ к SNMP адресом сервера SwitchMap.

# Community {#community}

Community — это просто строка, которую коммутатор сравнивает с присланной. Для чтения обычно создают community с правами **RO** (read-only). В SwitchMap её вводят в поле **Community**. При поиске по сети можно указать несколько через запятую.

# SNMPv3 {#snmpv3}

В v3 на коммутаторе создаётся **пользователь** с двумя паролями:

- **Аутентификация** (SHA, SHA-256 и другие, устаревший MD5) — подтверждает, что запрос пришёл от вас и не был изменён по дороге.
- **Шифрование** (AES128 и другие, устаревший DES) — скрывает содержимое ответов.

Уровни безопасности:

| Уровень | Аутентификация | Шифрование |
|---|---|---|
| noAuthNoPriv | нет | нет |
| authNoPriv | да | нет |
| authPriv | да | да — рекомендуется |

В SwitchMap укажите тот же **алгоритм** и те же **пароли**, что на коммутаторе. Пароли — не короче 8 символов (так требует стандарт).

**Контекст** обычно оставляют пустым. Он нужен, например, на коммутаторах Cisco, где таблица MAC-адресов отдельного VLAN читается через контекст `vlan-10`.

Пароли SNMPv3 хранятся в базе SwitchMap в зашифрованном виде, а ключ шифрования — в отдельном файле `switchmap.secret`.

# Что SwitchMap читает {#what}

| Данные | Откуда (MIB) |
|---|---|
| Название, описание, место установки | SNMPv2-MIB (system) |
| Порты, их состояние, скорость, счётчики трафика и ошибок | IF-MIB |
| Описания портов (ifAlias) | IF-MIB |
| MAC-адреса на портах | BRIDGE-MIB, Q-BRIDGE-MIB |
| VLAN портов | Q-BRIDGE-MIB |
| Соседи | LLDP-MIB |
| CPU, память, температура | разные — зависят от производителя |
| PoE | POWER-ETHERNET-MIB |

Если какой-то части данных нет — коммутатор её не отдаёт по SNMP или для неё нужен другой контекст. Остальное работает.
