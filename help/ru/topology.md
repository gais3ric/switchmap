Страница **Топология** рисует, какой коммутатор с каким соединён и через какие порты. Данные берутся из **LLDP** — протокола, по которому соседние устройства рассказывают друг другу о себе.

# Что нужно {#requirements}

1. Включить LLDP на коммутаторах — команды для разных производителей в статье [Включение SNMP](/help/snmp-vendors). На многих моделях он включён по умолчанию.
2. Коммутаторы должны быть добавлены в SwitchMap с IP-адресом и доступом по SNMP.

# Как читать карту {#read}

Условные обозначения — в углу карты:

| Обозначение | Что это |
|---|---|
| Синяя полоска | Коммутатор из SwitchMap; точка показывает, доступен ли он |
| Голубая полоска | Сервер или устройство, привязанное к порту |
| Оранжевая полоска | Неизвестный LLDP-сосед — устройство, которого нет в SwitchMap (точка доступа, IP-телефон, другой коммутатор) |
| Сплошная линия | Физическая связь по LLDP |
| Пунктир | Устройство, привязанное к порту вручную |

При наведении на линию видны порты с обеих сторон.

Карту можно двигать мышью, масштабировать колёсиком, а кнопка **Вписать** возвращает её целиком на экран. Щелчок по коммутатору — карточка с кнопкой **Открыть коммутатор**.

> **Совет:** при [поиске по сети](/help/add-switch#discovery) с галочкой **Идти по соседям LLDP** SwitchMap сам найдёт коммутаторы, которые видны на этой карте как соседи.

# Если связей нет {#empty}

- LLDP выключен на коммутаторе или на отдельных портах.
- Коммутатор не отдаёт LLDP-MIB по SNMP (так бывает у простых моделей).
- Некоторые устройства Cisco по умолчанию используют только CDP — включите LLDP командой `lldp run`.
