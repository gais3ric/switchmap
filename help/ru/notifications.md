Уведомления приходят о тех же событиях, что видны в колокольчике: коммутатор недоступен, порт упал, высокая загрузка, ошибки, перегрев. Настраиваются на странице **Уведомления** (значок самолётика, только администратор).

> **Важно:** события появляются только при опросе. Включите **Периодический опрос** в **Настройках**, иначе сообщать будет не о чем.

# Telegram {#telegram}

1. В Telegram откройте **@BotFather**, отправьте `/newbot`, придумайте имя бота. BotFather пришлёт **токен** вида `123456789:AAH…` — вставьте его в поле **Токен бота**.
2. Напишите своему боту любое сообщение (например, `/start`). Для группы — добавьте бота в группу и напишите там что-нибудь.
3. Нажмите **Найти чаты** и добавьте нужный чат. Номер чата можно ввести и вручную: у групп он начинается с минуса.
4. Включите канал, выберите события и нажмите **Сохранить**. Кнопка **Отправить тестовое сообщение** проверит, что всё работает.

Серверу SwitchMap нужен доступ к `api.telegram.org` по HTTPS. Если в интернет он выходит через прокси — укажите его в поле **HTTP-прокси** (`http://proxy:3128` или `http://логин:пароль@proxy:3128`).

# Почта {#email}

1. Нажмите кнопку своего почтового сервиса — подставятся сервер, порт и шифрование. Для корпоративной почты укажите их сами.
2. **Логин** — обычно адрес почты. **Пароль приложения** — см. ниже.
3. **Получатели** — один или несколько адресов через запятую.
4. Нажмите **Отправить тестовое письмо**, затем **Сохранить**.

| Порт | Шифрование |
|---|---|
| 465 | SSL |
| 587 | STARTTLS |
| 25 | Без шифрования (только внутренний сервер) |

> **Важно:** Gmail, Яндекс, Mail.ru и Outlook не принимают обычный пароль от почты. В настройках безопасности почтового ящика создайте **пароль приложения** и укажите его.

# Чтобы сообщений не было слишком много {#filters}

| Настройка | Что делает |
|---|---|
| Выбор событий | Например, только «коммутатор недоступен» и «порт упал» |
| О восстановлении | Сообщать ли «порт поднялся», «снова доступен» |
| Только важные порты | Только порты с описанием на коммутаторе, подключением на схеме или транком — без компьютеров пользователей |
| Тихие часы | Ночью приходят только критичные события |
| «Мигающий» порт | Порт, который падает и поднимается много раз за час, — одно предупреждение вместо десятков сообщений |

Несколько событий одного опроса приходят одним сообщением. Если сеть или Telegram были недоступны, сообщения отправятся позже — SwitchMap повторяет попытки. Старые события (больше суток) не досылаются — они есть в журнале событий.
